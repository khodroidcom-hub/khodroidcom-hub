We are building tools that connect vehicle information with automotive parts discovery.

| Focus | What we work on |
| :--- | :--- |
| Vehicle catalog | Structured information about vehicle brands, models and submodels |
| Parts discovery | Clear navigation between vehicles, categories and parts |
| Data quality | Traceable sources and evidence for compatibility claims |
| Reliable delivery | Tested changes, staged releases and recovery planning |

**Technology:** TypeScript · Next.js · NestJS · MariaDB
